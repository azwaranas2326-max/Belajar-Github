# Muhammad Azwar Anas — Portfolio

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka file `index.html` di Chrome/Edge/Firefox.
3. Website dapat langsung berjalan tanpa server.

## Mengganti foto profil
Di `index.html`, cari elemen:
`<div class="photo" id="photoBox">`
Anda dapat menggantinya dengan:
`<img src="foto.jpg" alt="Muhammad Azwar Anas">`
dan simpan `foto.jpg` di folder yang sama.

## Mengganti project
Cari bagian `PROJECT / 01` dan `PROJECT / 02`, lalu ubah judul, deskripsi, teknologi, dan link sesuai project Anda.

## Catatan
Semua data yang belum diberikan dibuat sebagai placeholder/area yang mudah diedit.
